# 02. 교육 당일 워크플로우 (강사용)

대상: Isaac Sim 기초(Lv1)를 마친 교육생. 교육생 1명당 Windows VM 1대(NVIDIA A10).
VM은 [01_VM_사전세팅.md](01_VM_사전세팅.md) 상태로 준비되어 있어야 한다: 기본 시연 15개 있음, 학습된 모델 없음, YOLO 미설치.

시간은 개발 PC(노트북 RTX 5070 Ti) 측정과 추정이다. **A10 VM에서 리허설로 다시 잴 것.**

## 0. 도입 (10분)

- 오늘의 목표: "내가 운전한 기록으로 AI가 파렛트를 2층 선반에 올리게 만든다."
- 두 가지 학습을 한다.
  - **운전 경로 학습**: 사람이 지나간 경로를 기억 → AI가 출발 전에 머릿속으로 연습 → 가장 정확한 경로를 따라감
  - **YOLO 학습**: 포크 카메라로 파렛트를 찾아 남은 거리를 잼 ("AI의 눈")
- 원리 설명 자료: [03_모방학습_원리.md](03_모방학습_원리.md). 특히 2절 "키를 그대로 흉내 내면 왜 실패했나"가 좋은 도입 이야기다.
- YOLO는 AGPL-3.0이라 교육 자료에 넣지 않고 각자 설치한다는 점을 먼저 알린다.

## 1. YOLO 설치 걸어 두기 (5분 + 대기)

교육생 교재: `isaacsim-edu-lv2\Isaacsim_Edu_ForkliftAI\docs\YOLO_실습.md` 0~3절.

- PyTorch GPU판 다운로드가 약 3 GB라 시간이 걸린다. **cmd 창에서 설치를 시작해 두고** Isaac Sim으로 넘어간다.
- 2절 확인 명령에서 `True NVIDIA A10` 이 나오는지는 Lesson 1이 끝난 뒤 함께 확인한다.

## 2. Lesson 1 지게차 시뮬레이션 (15~20분)

1. Isaac Sim → **AZ Edu Lv2** 창 → **Lesson 1 · 지게차 시뮬레이션**.
2. 시작(Play) → 방향키로 운전, Left Shift = 포크 올림, Left Ctrl = 포크 내림.
3. 목표: 파렛트 구멍에 포크를 넣고 → 들어 올려서 → 2층 선반에 내려놓고 → 포크 빼기.
4. 포인트: 포크 구멍은 한 방향으로만 들어간다. 비스듬히 들어가면 파렛트가 밀린다. 이 감각이 다음 녹화의 질을 정한다.

## 3. Lesson 2 둘러보기 (5분)

1. **Lesson 2 · 지게차 AI** 버튼. 지게차 AI 전용 장면과 "AZ Edu Lv2 - Lesson 2" 창이 뜬다.
2. **모인 시연 데이터** 표: 강사가 준비한 기본 시연 15개 (같은 방향 출발 10개 + 회전 출발 5개).
3. **AI 카메라 화면 보기**: AI는 포크 사이 카메라로 본다. 운전석 화면과 비교.
4. **▶ AI 운전 시작이 눌리지 않는다**: 아직 경로 학습을 안 했기 때문이다 (`paths.json` 없음).

## 4. 시연 녹화 5개 (15분)

1. 출발 위치를 정한다: 세로 · 가로 · **회전** 슬라이더, 또는 **랜덤**(시작할 때마다 위치 · 방향 무작위).
2. **● 녹화 시작** → 운전 → 파렛트를 2층에 올리고 포크를 뺀 뒤 **■ 녹화 끝내기**.
3. 결과가 "파렛트가 2층에 놓이지 않음"이면 **마지막 녹화 지우기**.
4. 5개를 모은다. 권장: 기본 시연에 적은 **방향**(예: 45°, 135°, -135°처럼 비스듬한 출발)을 일부러 넣는다.

알아 둘 것:
- 지게차가 선반 · 기둥 · 파렛트와 겹친 자리에서는 녹화가 시작되지 않고 이유가 상태 글로 나온다.
- 녹화 1회는 운전 25~60초 + 준비 · 초기화. 5회에 10~15분.
- 녹화 데이터 위치: **데이터 폴더 열기** 버튼 (`C:\isaacsimProjects\forklift_ai\demos`).

## 5. 경로 학습 (5분)

설치가 끝난 YOLO 가상환경의 Python으로 실행한다 (numpy가 들어 있다).

```
C:\isaacsimProjects\forklift_ai\yolo-venv\Scripts\python.exe C:\isaacsimProjects\isaacsim-edu-lv2\Isaacsim_Edu_ForkliftAI\tools\learn_paths.py
```

- 약 10초. `C:\isaacsimProjects\forklift_ai\models\paths.json` 이 생긴다.
- 출력 읽는 법: `F1.9 B4.2 F2.6 ...` = 전진 1.9 m → 후진 4.2 m → ... / `1 cm` = 그 경로를 자기 출발점에서 다시 따라갔을 때 포크 끝 오차 /
  `들어간 각도` = 파렛트 구멍 방향과의 차이 (35° 넘으면 AI가 쓰지 않음).
- 오차가 수십 cm인 시연은 "AI가 따라 하기 어려운 운전"이다. 지우고 다시 녹화하거나 그대로 비교 사례로 쓴다.
- Isaac Sim 창은 그대로 두면 된다. 창의 "학습된 경로: 시연 20개"가 자동으로 갱신되고 AI 운전 시작이 켜진다.

## 6. AI 운전 — YOLO 없음 (10~15분)

1. **파렛트 거리 판단 = YOLO 없음** (아직 YOLO 모델이 없으므로 어차피 이렇게 동작한다).
2. 출발 위치 · 방향을 바꿔 가며 **▶ AI 운전 시작**.
3. 볼 것:
   - "45가지 방법을 머릿속으로 연습 → 'demo_...' 경로 선택": 어떤 시연을 골랐나 (내 시연이 뽑히나?)
   - 키 표시: AI가 지금 누르는 키
   - **AI 운전 기록** 표: 출발 위치별 성공 · 실패, 고른 경로
4. 실패하면 **자리 고쳐 잡기**를 켜고 다시 해 본다 (갈 경로가 없을 때 조금씩 움직여 아는 자리로 감).
5. 운전이 끝나면 마지막 장면이 멈춘 채 남는다. **AI 멈춤**(또는 Stop)으로 초기화해야 녹화를 다시 할 수 있다.

## 7. YOLO 학습 (25분)

교재 `YOLO_실습.md` 4~7절.

1. 데이터셋 만들기 (수 초)
2. 학습 `epochs=50` (개발 PC 약 15분). **학습하는 동안 Isaac Sim을 끄면 2~3배 빠르다.**
   시간이 빠듯하면 `epochs=30` (약 8~9분, 정확도 차이 0.003).
3. 결과 보기: `results.png`, `val_batch0_pred.jpg`
4. ONNX 내보내기 → `runs\my_forklift\weights\best.onnx`

기준: mAP50 0.8 미만이면 학습이 잘 안 된 것이다. 데이터셋 만들기부터 다시 확인한다.
(강사 모델은 배포하지 않으므로 예비 모델로 넘어가는 방법은 없다. 시간이 모자라면 YOLO 없음으로 8단계를 대신한다.)

## 8. AI 운전 — YOLO 사용 (10분)

1. Isaac Sim을 껐다면 다시 켜고 Lesson 2를 연다. 새 `best.onnx`는 자동으로 쓰인다.
2. **파렛트 거리 판단 = YOLO 사용**으로 AI 운전. 상태 글의 "들어 올린 순간 파렛트까지: 실제 2.03 m · AI 판단 1.99 m"를 본다.
3. **파렛트 뒤로** 슬라이더로 파렛트를 옮긴 뒤 YOLO 사용 / YOLO 없음을 비교한다.
   - YOLO 사용: 카메라로 거리를 재서 포크가 다 들어간 곳에서 들어 올린다.
   - YOLO 없음: 녹화 경로가 끝나는 곳에서 들어 올린다 (파렛트가 옮겨져 있으면 어긋날 것으로 예상).
   - ⚠ 이 비교는 개발 중에 나란히 측정하지 않았다. **리허설 때 강사가 먼저 해 볼 것.**

## 9. 정리 · 토론 (10분)

- 기본 시연 15개 → 내 시연을 더한 20개: AI 운전 기록 표에서 무엇이 달라졌나.
- 실패한 출발 방향은 어디였나 → 그 방향의 시연을 더 녹화하면 된다 ("데이터의 다양성").
- 키를 그대로 흉내 내는 AI가 왜 실패했나 (분포 이동) vs 경로를 배우고 연습하는 AI.
- 실제 무인 지게차: 인식(카메라 · AI) + 계획 + 제어로 나눈다.
