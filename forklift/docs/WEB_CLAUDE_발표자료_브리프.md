## 4. 지켜야 할 것

- **숫자는 문서에 있는 것만 쓴다.** 만들어 내지 않는다. 문서에 "측정 안 함", "추정"이라고 적힌 것은 슬라이드에도 그렇게 표시한다.
  - 예: A10 VM에서의 학습 시간은 아직 재지 않았다. YOLO 사용 vs 없음의 나란한 비교도 아직 측정하지 않았다.
- **민감 정보를 넣지 않는다:** ID, 비밀번호, 접속 주소(IP), 가격 · 비용, 고객 정보. 저장소 문서에도 넣지 않았다.
- 화면 캡처는 저장소에 없다. 필요한 자리에는 "[화면: Lesson 2 패널]"처럼 자리 표시만 두면 강사가 채운다.
- 브랜드 색: AZWELL 초록 `#76B343` (런처 · 버튼에 쓰는 색). 패널 배경은 어두운 회색 계열(`#2A2A25` 등).
- YOLO, Ultralytics, NVIDIA, Omniverse 로고는 쓰지 않는다. 이름만 텍스트로.

## 5. 핵심 메시지 (발표 전체에서 반복할 것)

1. AI는 **내가 운전한 기록**으로 배운다. 그래서 **어떤 운전을 녹화하느냐**가 AI의 실력을 정한다.
2. 키를 그대로 흉내 내는 것보다, **경로를 배우고 출발 전에 연습하는** 쪽이 훨씬 잘 된다.
3. YOLO는 운전을 배우지 않는다. **"얼마나 남았나"를 보는 눈**이다.
