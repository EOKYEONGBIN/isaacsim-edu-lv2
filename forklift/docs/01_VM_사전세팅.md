# 01. Windows VM 요구 사항과 사전 세팅 (강사 · VM 담당자용)

교육 전에 VM마다 한 번씩 해 둘 일이다. **YOLO(Ultralytics)는 미리 설치하지 않는다** (아래 3절, 라이선스 방침).

이 문서에는 계정 ID, 비밀번호, 접속 주소 같은 정보를 적지 않는다. 그런 정보는 VM 담당자가 따로 전달한다.

사전 세팅은 두 프로그램으로 한다. 둘 다 관리자 권한으로 실행되고, 로그는 `C:\ProgramData\AZEduLv2Tool\`에 남는다.

| 프로그램 | 하는 일 |
|---|---|
| `AZ Edu Lv2 익스텐션.exe` | 익스텐션 받기 · 업데이트(GitHub), 기본 시연 · 창고 장면 받기, Isaac Sim 검색 경로 등록 + 런처 자동 실행. Git이 없으면 설치 |
| `AZ Edu Lv2 실습환경.exe` | 실습 전 준비(Python · `yolo-venv` · PyTorch GPU판) / 실습 후 되돌리기 |

---

## 1. VM 요구 사항

| 항목 | 요구 사항 | 비고 |
|---|---|---|
| OS | Windows 10/11 64bit | 개발 · 검증은 Windows 11에서 함 |
| GPU | NVIDIA A10 (24 GB) 기준 | Isaac Sim과 YOLO 학습이 같은 GPU를 쓴다 |
| GPU 드라이버 | `nvidia-smi`의 **CUDA Version이 12.8 이상** | YOLO 실습의 PyTorch(cu128)와 Isaac Sim 6.2.0 모두 필요 |
| Isaac Sim | **6.2.0** | 개발 PC는 6.2.0 (rc.14 빌드)로 검증 |
| Python | **3.10 ~ 3.12** (python.org 설치판) | YOLO 가상환경용. 없으면 실습환경.exe가 3.12를 설치한다. Isaac Sim 안의 Python과 별개 |
| 디스크 여유 | **20 GB 이상** (Isaac Sim 설치 공간 제외) | 아래 표 참고 |
| 인터넷 | 아래 주소로 다운로드가 되어야 함 | 사전 세팅과 교육 당일 YOLO 설치에 필요 |

디스크 사용량 (개발 PC 실측, 2026-11-11):

| 항목 | 크기 |
|---|---|
| 창고 장면 `iw_hub_warehouse_navigation` | 0.73 GB |
| 기본 시연 15개 | 약 0.7 GB |
| 교육생 시연 5개 | 약 0.25 GB |
| YOLO 가상환경 `yolo-venv` (PyTorch GPU판 포함) | 4.8 GB |
| YOLO 학습 데이터 복사본 `yolo_dataset` | 시연 폴더와 비슷한 크기 (약 1 GB) |
| YOLO 학습 결과 1회 `runs\...` | 약 30 MB |

인터넷 접속이 필요한 곳:

| 언제 | 주소 | 무엇 |
|---|---|---|
| 사전 세팅 (익스텐션.exe) | `github.com` | 익스텐션 저장소, 기본 시연 · 창고 장면 zip, Git 설치 파일 |
| 사전 세팅 (실습환경.exe) | `www.python.org`, `download.pytorch.org`, `pypi.org` | Python 3.12, PyTorch GPU판 (약 3 GB) |
| 교육 당일 | `pypi.org`, `files.pythonhosted.org` | ultralytics, onnx 등 (교육생이 설치) |
| 교육 당일 | `github.com` | YOLO 기본 모델 `yolo11n.pt`, 글꼴 파일 (첫 학습 때 Ultralytics가 자동으로 받음) |

> 방화벽 · 프록시로 막혀 있으면 교육 당일 설치가 멈춘다. 사전 점검 때 4절의 "YOLO 설치 리허설"로 꼭 확인한다.

## 2. 설치 순서

### 2-1. Isaac Sim 6.2.0

1. Isaac Sim 6.2.0을 설치한다.
2. **한 번 실행했다가 끈다.** 처음 실행할 때 셰이더를 컴파일하느라 수 분이 걸리고, 이때 Isaac Sim 설정 파일이 생긴다
   (익스텐션.exe가 검색 경로를 등록하려면 이 파일이 있어야 한다).

### 2-2. 교육 파일 받기 + Isaac Sim 등록 — `AZ Edu Lv2 익스텐션.exe`

1. Isaac Sim을 끈다.
2. `AZ Edu Lv2 익스텐션.exe`를 `E:\omniverse\content\`에 두고 실행 → **설치 / 업데이트**.
3. 끝나면 아래가 모두 되어 있다. 상태 창에 "설치 완료, 최신 상태입니다."가 나오면 된다.

```
E:\omniverse\content\
├─ isaacsim-edu-lv2\                 ← 이 저장소 (GitHub에서 받음)
│    ├─ forklift\                    ← 지게차 익스텐션 (검색 경로로 등록됨)
│    ├─ cosmos\                      ← Cosmos 익스텐션 자리 (검색 경로로 등록됨)
│    └─ ExtensionRoot.config         ← 검색 경로 · 자동 실행 목록
├─ iw_hub_warehouse_navigation\      ← 창고 장면
│    ├─ iw_hub_warehouse_navigation.usd       (Lesson 1)
│    └─ iw_hub_warehouse_forklift_ai.usd      (Lesson 2 지게차 AI)
└─ forklift_ai\
     └─ demos\demo_*                 ← 기본 시연 15개
```

- Isaac Sim 6.2의 Extension Search Paths에 `isaacsim-edu-lv2\forklift`, `isaacsim-edu-lv2\cosmos`가 등록되고,
  런처 `Isaacsim_Edu_Lv2`가 Enabled + Autoload로 켜진다.
- 익스텐션은 경로를 고정해 두지 않고 `isaacsim-edu-lv2` 폴더의 바로 위 폴더를 기준으로 장면 · 데이터를 찾는다.
  세 폴더가 같은 폴더 안에 있기만 하면 된다.
- 익스텐션이 바뀌었을 때도 같은 exe를 다시 실행하면 GitHub의 최신 버전으로 맞춘다. 이미 있는 시연 · 장면은 덮어쓰지 않는다.
- **학습된 모델은 넣지 않는다.** `forklift_ai\models\`, `forklift_ai\runs\`가 없어야 교육생이 처음부터 학습하는 흐름이 된다.

인터넷이 안 되는 VM은 배포 압축 파일(`교육생VM.zip`)을 `E:\omniverse\content\`에 그대로 풀고, Isaac Sim에서 직접 등록한다:
**Window > Extensions** → 오른쪽 위 ≡(설정) → **Extension Search Paths**에 `E:/omniverse/content/isaacsim-edu-lv2/forklift` 추가 →
Extensions 창에서 `Isaacsim_Edu_Lv2`를 **Enabled · Autoload**로 켠다.

Isaac Sim을 켜면 메뉴 **Azwell > AZ Edu Lv2** 창이 Stage 옆에 뜬다.
- `Isaacsim_Edu_Lv2_Lesson1`, `Isaacsim_Edu_ForkliftAI`는 **켜지 않는다.** 런처 버튼이 켠다.
- Lv1 런처(`Isaacsim_Edu_Lv1`)도 같은 VM에 있으면, Lv2 창은 Lv1 창 옆에 탭으로 붙는다.

### 2-3. YOLO용 Python 준비 — `AZ Edu Lv2 실습환경.exe` "실습 전 준비"

1. `E:\omniverse\content\AZ Edu Lv2 실습환경.exe` 실행 → **실습 전 준비**.
2. Python 3.10 ~ 3.12가 없으면 python.org의 3.12를 설치하고, `forklift_ai\yolo-venv`를 만들어 PyTorch GPU판(cu128)을 설치한다
   (약 3 GB 다운로드, 수 분). GPU 사용을 확인하고, 이 상태의 패키지 목록을 `yolo-venv\azwell_baseline.txt`에 기록한다.
3. 상태 창에 **"실습 전 상태입니다"** 가 나오면 된다.

YOLO(ultralytics)는 설치하지 않는다. 교육생이 당일 직접 설치한다 (3절).

## 3. YOLO 라이선스 방침 — 교육생이 직접 설치하는 이유

- **YOLO(Ultralytics)는 AGPL-3.0 오픈소스**다. AGPL 소프트웨어를 우리 교육 자료나 VM 이미지에 넣어 나눠 주면,
  배포하는 쪽에 AGPL 의무(소스 공개 등)가 생길 수 있다.
- 그래서 이 교육은 다음처럼 나눈다.

| 구분 | 누가 · 어떻게 |
|---|---|
| 가상환경 `yolo-venv` + PyTorch GPU판 | **미리 설치** (실습환경.exe). PyTorch는 BSD 라이선스라 AGPL 의무가 없다 |
| YOLO 설치 (`pip install ultralytics`) | **교육생이 직접** PyPI에서 받아 가상환경에 설치 |
| YOLO 기본 모델 `yolo11n.pt` | 교육생의 첫 학습 때 Ultralytics가 자동으로 받음. 우리가 배포하지 않음 |
| YOLO 학습 · ONNX 내보내기 | 교육생이 공식 `yolo` 명령으로 직접 실행 |
| 강사가 미리 학습한 모델 | **배포하지 않음** (VM에 넣지 않음) |
| 우리 익스텐션 · 스크립트 | `ultralytics`를 **import하지 않음.** 교육생이 내보낸 ONNX 파일만 Isaac Sim 내장 `onnxruntime`(`isaacsim.pip.onnx`)으로 읽음 |
| `tools/make_yolo_dataset.py`, `tools/learn_paths.py` | 표준 Python · numpy만 사용 |

- 교육이 끝나면 실습환경.exe의 "실습 후 되돌리기"가 교육생이 설치한 ultralytics와 그 의존 패키지를 지워, 다음 교육 전에도
  VM에 YOLO가 남지 않게 한다.
- 이 방침은 개발 중에 정한 운영 원칙이다. 법률 검토를 거친 결론은 아니므로, 외부 고객 대상 교육이나 판매형 교육으로
  바꿀 때는 법무 확인을 받는다.

## 4. 사전 점검 (교육 전날까지, VM마다)

| # | 확인 | 기대 결과 |
|---|---|---|
| 1 | `nvidia-smi` | GPU(A10)가 보이고 CUDA Version 12.8 이상 |
| 2 | 익스텐션.exe → 상태 확인 | "설치 완료, 최신 상태입니다." |
| 3 | 실습환경.exe → 상태 확인 | "실습 전 상태입니다" (PyTorch GPU 사용 가능, YOLO 없음, 기본 시연 15개) |
| 4 | Isaac Sim 실행 | Azwell > AZ Edu Lv2 창이 뜸 |
| 5 | Lesson 1 버튼 | 창고 장면이 열리고 Play 후 방향키로 지게차가 움직임 |
| 6 | Lesson 2 버튼 | 지게차 AI 창이 뜨고 "모인 시연 데이터"가 **15개** |
| 7 | Lesson 2 "AI 운전 시작" | **눌리지 않는 상태**가 정상 (학습된 경로가 아직 없음) |
| 8 | YOLO 설치 리허설 | cmd에서 `실습_명령어.txt`의 1 · 2 · 3번을 해 보고 `yolo checks`가 되는지 확인 (인터넷 · 방화벽 점검). **확인 후 실습환경.exe → "실습 후 되돌리기"** |

## 5. 교육이 끝난 뒤 다음 교육을 위해 되돌리기

Isaac Sim과 cmd 창을 닫고 `AZ Edu Lv2 실습환경.exe` → **실습 후 되돌리기**. 지울 목록을 보여 주고 확인을 받은 뒤 지운다.

| 지우는 것 | 경로 |
|---|---|
| 교육생 시연 (기본 15개 외) | `forklift_ai\demos\` 안에서 기본 15개가 아닌 폴더 |
| 학습된 경로 · YOLO 학습 결과 · 학습 데이터 | `forklift_ai\models\`, `forklift_ai\runs\`, `forklift_ai\yolo_dataset\` |
| AI 운전 기록 | `forklift_ai\ai_runs.csv` |
| 내려받은 YOLO 가중치 | `forklift_ai\*.pt`, `*.onnx` |
| Ultralytics 설정 · 글꼴 | `%APPDATA%\Ultralytics` |
| 교육생이 설치한 패키지 | `yolo-venv`에서 실습 전 목록(`azwell_baseline.txt`)에 없는 패키지 (ultralytics 등) |

- 가상환경 `yolo-venv`와 PyTorch는 **남긴다.** 다음 교육에서 다시 내려받지 않아도 된다.
- 끝나면 상태 창에 "실습 전 상태입니다"가 나온다.
- **강사 PC에서는 쓰지 않는다.** 미리 학습한 모델(`models`, `runs`)도 지워진다.
