# 01. Windows VM 요구 사항과 사전 세팅 (강사 · VM 담당자용)

교육 전에 VM마다 한 번씩 해 둘 일이다. **YOLO(Ultralytics)는 미리 설치하지 않는다** (아래 3절, 라이선스 방침).

이 문서에는 계정 ID, 비밀번호, 접속 주소 같은 정보를 적지 않는다. 그런 정보는 VM 담당자가 따로 전달한다.

---

## 1. VM 요구 사항

| 항목 | 요구 사항 | 비고 |
|---|---|---|
| OS | Windows 10/11 64bit | 개발 · 검증은 Windows 11에서 함 |
| GPU | NVIDIA A10 (24 GB) 기준 | Isaac Sim과 YOLO 학습이 같은 GPU를 쓴다 |
| GPU 드라이버 | `nvidia-smi`의 **CUDA Version이 12.8 이상** | YOLO 실습의 PyTorch(cu128)와 Isaac Sim 6.2.0 모두 필요 |
| Isaac Sim | **6.2.0**, `C:\isaacsim6.2.0` | 개발 PC는 6.2.0 (rc.14 빌드)로 검증 |
| Python | **3.10 ~ 3.12** (python.org 설치판, PATH 등록) | YOLO 가상환경용. Isaac Sim 안의 Python과 별개 |
| 디스크 여유 | **20 GB 이상** (Isaac Sim 설치 공간 제외) | 아래 표 참고 |
| 인터넷 | 아래 주소로 다운로드가 되어야 함 | 교육 당일 YOLO 설치에 필요 |

디스크 사용량 (개발 PC 실측, 2026-11-11):

| 항목 | 크기 |
|---|---|
| 창고 장면 `iw_hub_warehouse_navigation` | 0.73 GB |
| 기본 시연 15개 | 약 0.7 GB (20개 0.95 GB 기준 환산) |
| 교육생 시연 5개 | 약 0.25 GB |
| YOLO 가상환경 `yolo-venv` (PyTorch GPU판 포함) | 4.8 GB |
| YOLO 학습 데이터 복사본 `yolo_dataset` | 시연 폴더와 비슷한 크기 (약 1 GB) |
| YOLO 학습 결과 1회 `runs\...` | 약 30 MB |

인터넷 접속이 필요한 곳 (교육생 YOLO 설치 · 첫 학습 때):

- `pypi.org`, `files.pythonhosted.org`: ultralytics, onnx 등
- `download.pytorch.org`: PyTorch GPU판 (약 3 GB)
- `github.com`: YOLO 기본 모델 `yolo11n.pt`, 글꼴 파일 (첫 학습 때 Ultralytics가 자동으로 받음)

> 방화벽 · 프록시로 막혀 있으면 교육 당일 설치가 멈춘다. 사전 점검 때 4절의 "설치 리허설"로 꼭 확인한다.

## 2. 설치 순서

### 2-1. Isaac Sim 6.2.0

1. `C:\isaacsim6.2.0`에 설치한다.
2. **한 번 실행해 둔다.** 처음 실행할 때 셰이더를 컴파일하느라 수 분이 걸린다. 교육 당일 첫 실행이 늦어지지 않게 미리 해 둔다.

### 2-2. 교육 파일 배치

모두 `E:\omniverse\content` 아래에 나란히 둔다. 익스텐션은 경로를 고정해 두지 않고 `isaacsim-edu-lv2` 폴더의 바로 위 폴더를 기준으로
장면 · 데이터를 찾는다. 세 폴더가 같은 폴더 안에 있기만 하면 된다.

> 배포 압축 파일(`AZ_Edu_Lv2_교육생VM_<날짜>.zip`)을 받았다면 아래 1~3 대신 `E:\omniverse\content\`에 그대로 풀면 된다.

```
E:\omniverse\content\
├─ isaacsim-edu-lv2\                 ← 이 저장소 (git clone). 지게차 익스텐션은 forklift\ 안에 있다
├─ iw_hub_warehouse_navigation\      ← 창고 장면 폴더 (강사가 복사)
│    ├─ iw_hub_warehouse_navigation.usd       (Lesson 1)
│    └─ iw_hub_warehouse_forklift_ai.usd      (Lesson 2 지게차 AI)
└─ forklift_ai\
     └─ demos\demo_*                 ← 기본 시연 15개 (Release zip 압축 해제)
```

1. 저장소 받기
   ```
   cd E:\omniverse\content
   git clone https://github.com/EOKYEONGBIN/isaacsim-edu-lv2.git
   ```
   (공개 저장소다. `AZ Edu Lv2 익스텐션.exe`를 쓰면 1~3과 아래 검색 경로 등록을 자동으로 한다.)
2. **창고 장면 폴더**를 `E:\omniverse\content\iw_hub_warehouse_navigation\`에 복사한다. Lv1과 같은 폴더이고, 저장소에는 들어 있지 않다.
   지게차 AI용 장면 `iw_hub_warehouse_forklift_ai.usd`가 같은 폴더에 있어야 한다.
3. **기본 시연 15개**: 저장소 Release의 `forklift_ai_demos15.zip`을 받아 `E:\omniverse\content\`에 압축을 푼다.
   `E:\omniverse\content\forklift_ai\demos\demo_...` 폴더 15개가 생기면 된다.
4. **학습된 모델은 넣지 않는다.** `forklift_ai\models\`, `forklift_ai\runs\`가 없어야 교육생이 처음부터 학습하는 흐름이 된다.

### 2-3. Isaac Sim에 익스텐션 등록

1. Isaac Sim 실행 → **Window > Extensions** → 오른쪽 위 ≡(설정) → **Extension Search Paths**에
   `E:/omniverse/content/isaacsim-edu-lv2/forklift` 추가.
2. Extensions 창에서 `Isaacsim_Edu_Lv2`를 찾아 **켜고(Enabled) · 자동 실행(Autoload)** 을 체크한다.
3. Isaac Sim을 다시 켜면 메뉴 **Azwell > AZ Edu Lv2** 창이 Stage 옆에 뜬다.
   - `Isaacsim_Edu_Lv2_Lesson1`, `Isaacsim_Edu_ForkliftAI`는 **켜지 않는다.** 런처 버튼이 켠다.
   - Lv1 런처(`Isaacsim_Edu_Lv1`)도 같은 VM에 있으면, Lv2 창은 Lv1 창 옆에 탭으로 붙는다.

### 2-4. Python (YOLO용)

- python.org에서 3.10 ~ 3.12를 설치하고 "Add python.exe to PATH"를 체크한다.
- 가상환경과 YOLO는 **만들지 않는다.** 교육생이 당일 직접 만든다 (3절).

## 3. YOLO 라이선스 방침 — 교육생이 직접 설치하는 이유

- **YOLO(Ultralytics)는 AGPL-3.0 오픈소스**다. AGPL 소프트웨어를 우리 교육 자료나 VM 이미지에 넣어 나눠 주면,
  배포하는 쪽에 AGPL 의무(소스 공개 등)가 생길 수 있다.
- 그래서 이 교육은 다음처럼 나눈다.

| 구분 | 누가 · 어떻게 |
|---|---|
| YOLO 설치 (`pip install ultralytics`) | **교육생이 직접** PyPI에서 받아 자기 가상환경에 설치 |
| YOLO 기본 모델 `yolo11n.pt` | 교육생의 첫 학습 때 Ultralytics가 자동으로 받음. 우리가 배포하지 않음 |
| YOLO 학습 · ONNX 내보내기 | 교육생이 공식 `yolo` 명령으로 직접 실행 |
| 강사가 미리 학습한 모델 | **배포하지 않음** (VM에 넣지 않음) |
| 우리 익스텐션 · 스크립트 | `ultralytics`를 **import하지 않음.** 교육생이 내보낸 ONNX 파일만 Isaac Sim 내장 `onnxruntime`(`isaacsim.pip.onnx`)으로 읽음 |
| `tools/make_yolo_dataset.py`, `tools/learn_paths.py` | 표준 Python · numpy만 사용 |

- VM 이미지에 `yolo-venv`를 미리 만들어 두는 것도 "우리가 설치해서 나눠 준 것"이 되므로 하지 않는다.
- 이 방침은 개발 중에 정한 운영 원칙이다. 법률 검토를 거친 결론은 아니므로, 외부 고객 대상 교육이나 판매형 교육으로
  바꿀 때는 법무 확인을 받는다.

## 4. 사전 점검 (교육 전날까지, VM마다)

| # | 확인 | 기대 결과 |
|---|---|---|
| 1 | `nvidia-smi` | GPU(A10)가 보이고 CUDA Version 12.8 이상 |
| 2 | `python --version` | 3.10 ~ 3.12 |
| 3 | Isaac Sim 실행 | Azwell > AZ Edu Lv2 창이 뜸 |
| 4 | Lesson 1 버튼 | 창고 장면이 열리고 Play 후 방향키로 지게차가 움직임 |
| 5 | Lesson 2 버튼 | 지게차 AI 창이 뜨고 "모인 시연 데이터"가 **15개** |
| 6 | Lesson 2 "AI 운전 시작" | **눌리지 않는 상태**가 정상 (학습된 경로가 아직 없음) |
| 7 | 설치 리허설 | 임시 폴더에서 `YOLO_실습.md` 1~3절대로 설치해 보고 `torch.cuda.is_available()`이 `True`인지 확인. **확인 후 그 가상환경은 지운다** |

## 5. 교육이 끝난 뒤 다음 교육을 위해 되돌리기

교육생이 만든 것만 지우면 처음 상태로 돌아간다.

| 지울 것 | 경로 |
|---|---|
| 교육생 시연 (기본 15개 외) | `E:\omniverse\content\forklift_ai\demos\` 안에서 교육 당일 날짜의 `demo_<날짜>_...` 폴더 |
| 학습된 경로 | `E:\omniverse\content\forklift_ai\models\` |
| YOLO 학습 결과 · 데이터 | `E:\omniverse\content\forklift_ai\runs\`, `E:\omniverse\content\forklift_ai\yolo_dataset\` |
| AI 운전 기록 | `E:\omniverse\content\forklift_ai\ai_runs.csv` |
| YOLO 가상환경 | `E:\omniverse\content\forklift_ai\yolo-venv\` |

가장 간단한 방법은 `forklift_ai` 폴더를 통째로 지우고 Release zip을 다시 푸는 것이다.
