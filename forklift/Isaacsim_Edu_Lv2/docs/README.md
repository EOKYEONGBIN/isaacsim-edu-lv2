# Isaac Sim Edu Lv2 (런처)

AZWELL Isaac Sim 교육 Lv2 런처. Azwell 메뉴에 "AZ Edu Lv2" 창을 추가하고, 버튼으로 레슨을 켠다.

| 버튼 | 익스텐션 | 내용 |
|---|---|---|
| Lesson 1 · 지게차 시뮬레이션 | `Isaacsim_Edu_Lv2_Lesson1` | 지게차를 키보드로 운전해 파렛트를 옮긴다 |
| Lesson 2 · 지게차 AI | `Isaacsim_Edu_ForkliftAI` | 시연 녹화 → 경로 학습·YOLO 학습 → AI 운전 |

- 한 번에 한 레슨만 켠다. 레슨을 켤 때 다른 Lv2 레슨과 켜져 있는 Lv1 레슨을 끈다.
- 시작할 때 Isaac Sim 기본 레이아웃으로 되돌리고 Stage 옆에 창을 붙인다(Lv1 런처와 같은 방식).
  Lv1 런처도 켜져 있으면 레이아웃을 다시 초기화하지 않고 Lv1 창 옆에 탭으로 붙는다.
- 마지막으로 켠 레슨을 기억했다가, Isaac Sim이 비정상 종료 후 다시 켜지면 그 레슨을 다시 켠다.
